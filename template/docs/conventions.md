# Quy chuẩn code

Thứ tự ưu tiên khi đặt quy chuẩn (càng lên trên càng tốt):
1. **Tool tự bắt** (linter, type checker, test) → đưa vào `eval/checks.sh`
2. **Hook tự chặn** → `.claude/hooks/`
3. **Ghi ở đây** → chỉ khi 1 và 2 không làm được

Mỗi quy tắc dưới đây phải trả lời: "Có biến nó thành check tự động được không?"
